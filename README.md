# dk-splits-robot

Test stage. `check_dk.py` opens the public DraftKings Network betting-splits
page for MLB, NFL, WNBA, CFB and NBA and reports whether it loaded and which
games it found. It is read-only: it writes nothing anywhere.

Run it from the **Actions** tab → **DK reachability test** → **Run workflow**.
The result shows on the run's summary page.
